# ⚡ Cotizador Web Interactivo

Un cotizador web dinámico, rápido e intuitivo desarrollado con HTML, CSS y JavaScript vainilla. Permite calcular presupuestos en tiempo real con una interfaz moderna en **Modo Oscuro** y detalles neón.

---

### ✨ Características
- 🎨 **Diseño Moderno:** Interfaz oscura (*Dark Mode*) con efectos de iluminación neón.
- 🚀 **Sin Recargas:** Procesamiento de datos instantáneo en el cliente utilizando `Event.preventDefault()`.
- 📱 **Totalmente Reponsivo:** Adaptado para visualizarse correctamente en dispositivos móviles y de escritorio.
- 🛠️ **Código Limpio:** Desarrollado sin librerías externas ni dependencias pesadas.

---

### 🛠️ Tecnologías Utilizadas
- **HTML5:** Estructura semántica del formulario.
- **CSS3:** Estilos avanzados, variables CSS y animaciones fluídas.
- **JavaScript (ES6+):** Manipulación del DOM y cálculo de variables en tiempo real.
